# PicStart 🚀

Um sistema CRUD básico desenvolvido como projeto prático, integrando uma API em **Spring Boot** (com persistência em memória via lista e segurança com **BCrypt**) com uma interface moderna em **React**. O projeto foi desenvolvido em ritmo de sprint durante **uma semana** (de 18 a 25 de agosto de 2026).

## 🛠️ Tecnologias Utilizadas

### Backend
* **Java & Spring Boot** — Construção da API RESTful.
* **Spring Security / BCrypt** — Criptografia aplicada para o salvamento dos dados.
* **Persistência em Lista** — Armazenamento estruturado em memória utilizando listas na aplicação.

### Frontend
* **React.js** — Biblioteca para construção da interface de usuário.
* **Axios / Fetch API** — Integração e consumo da API do backend.

---

## 📋 Funcionalidades (CRUD)

* **Create (Criar):** Cadastro de registros com processamento e segurança (criptografia BCrypt).
* **Read (Ler):** Listagem dos dados salvos na lista em memória da aplicação.
* **Update (Atualizar):** Modificação de registros existentes.
* **Delete (Excluir):** Remoção de itens da lista.
